# Exploratory-Data-Analysis-on-Flipkart
The Flipkart platform provides a vast selection of laptops with varying prices, specifications, and ratings, making it challenging for customers and sellers to understand market dynamics. This project aims to perform EDA on Flipkart laptop data to investigate pricing patterns, brand performance, customer rating trends.
The analysis will uncover key insights that help consumers make better purchasing decisions and assist retailers in designing competitive pricing and feature strategies.
To understand the structure and characteristics of the Flipkart laptop dataset.
To analyze the pricing trends of laptops across different brands and configurations
To compare brand-wise performance based on customer ratings and pricing
To identify feature combinations that offer the best value for money
